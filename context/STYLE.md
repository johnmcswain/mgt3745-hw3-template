# STYLE.md

**Status:** Not yet in use. Arrives in Module 4.

## Preview
STANDARDS.md governs the code. STYLE.md governs what the user sees: color, type, spacing,
voice. In Module 4 you will write it in a hybrid format: YAML frontmatter holding design
tokens a machine can read (`--color-primary: #051E39`), markdown body holding the rationale
only a human cares about ("navy because the client is a university and blue reads as trust").

The design kit (Mobbin, impeccable.style, Laws of UX) feeds this file. Bring a screenshot of
one interface you admire and one you resent. Both are data.

# EVALS.md

**Status:** Not yet in use. Arrives in Module 5.

## Preview
The verification table you wrote at the bottom of FEATURES.md this week graduates here.
In Module 5 it grows: a Riskiest Assumption statement, success criteria written before the
build, an error-analysis log, and two kinds of eval (one a script can run, one a human must
judge). For non-deterministic systems, the eval suite *is* the requirements document.

"AI PM" job postings now list evals by name. This file is the one employers ask about.
